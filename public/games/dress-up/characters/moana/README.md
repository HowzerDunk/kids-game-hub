# Moana base character

`moana-base.webp` is a generated, transparent dress-up cutout based on the official character portrait published on the [Disney Princess Moana page](https://princess.disney.com/moana).

It uses the shared 768 × 1152 character canvas defined in `src/games/dress-up/characters/moana.js`. Future replacement artwork should keep that canvas and pose alignment so the vector wardrobe continues to fit.
